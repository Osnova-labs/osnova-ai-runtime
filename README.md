# osnova-ai-runtime

Опциональный локальный AI runtime для Osnova.

## Статус

Стартовая основа runtime boundary.

## Лицензия

Apache-2.0.

## Назначение

Этот репозиторий предназначен для локальных AI-возможностей, которые не должны встраиваться напрямую в desktop-клиент. Runtime должен оставаться опциональным. Проекты Osnova должны быть полезны без него.

## Команды

```bash
pnpm install
pnpm build
pnpm start
pnpm typecheck
```

## Связанные репозитории

- `osnova-desktop` взаимодействует с runtime через локальный API.
- `osnova-core` отвечает за project и manifest primitives.
- `osnova-spec` отвечает за долговечные файловые контракты проекта.

## Правила участия

Граница процесса должна оставаться узкой. Не храните source-of-truth данные проекта в runtime caches. Сохраненный AI output должен попадать в папку проекта только через явное действие пользователя.
