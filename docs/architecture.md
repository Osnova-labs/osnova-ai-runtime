# Архитектура runtime

`osnova-ai-runtime` - локальная process boundary для опциональных AI-функций.

## Ответственность

- Отдавать health и capability status локального runtime.
- Размещать будущие интеграции model providers.
- Держать runtime caches отдельно от долговечных файлов проекта.
- Предоставлять узкий API для desktop-клиента.

## Не входит в ответственность

- Владение форматом проекта Osnova.
- Замена Markdown-конспектов, карточек или manifest-файлов.
- Требование удаленной учетной записи для локального использования проекта.
